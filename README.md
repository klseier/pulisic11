# Сайт фан-сторінки @c.pulisic11 (EN / IT)

Головне на сайті — публікації фан-сторінки `@c.pulisic11`: стрічка постів із сортуванням (нові / за лайками / за коментарями), аналітика (пости за 30 днів, середні лайки й коментарі, engagement, найкращий день для публікацій, топ-пост), графік лайків по постах і графік росту підписників. Профіль самого гравця `@cmpulisic` винесено в окремий компактний віджет з превʼю його останніх постів. Нижче — матчі, таблиці, статистика за Мілан і профіль гравця.

Статичний сайт без збірки й без залежностей. Його можна відкрити локально (подвійний клік на `index.html`) або викласти на будь-який безкоштовний хостинг.

## Структура

```
index.html                    сторінка
assets/styles.css             стилі
assets/app.js                 логіка, графіки, віджети
assets/i18n.js                усі тексти англійською та італійською
assets/data.js                ДАНІ (знімок станом на 9.11.2026), їх редагують вручну
scripts/update.mjs            необов'язкове щоденне автооновлення
.github/workflows/update-data.yml   запуск автооновлення в GitHub Actions
```

Мова вибирається автоматично (італійська для браузерів з `it`, інакше англійська), перемикач EN/IT вгорі. Пряме посилання на потрібну мову: `?lang=it` або `?lang=en`.

## Розміщення

**GitHub Pages (рекомендовано, бо тоді працює автооновлення)**
1. Створіть публічний репозиторій і завантажте в нього весь вміст папки (разом із прихованою папкою `.github`).
2. Settings → Pages → Source: *Deploy from a branch*, гілка `main`, папка `/ (root)`.
3. За хвилину сайт буде доступний за адресою `https://<логін>.github.io/<репозиторій>/`.

**Netlify / Cloudflare Pages:** перетягніть папку на app.netlify.com/drop. Автооновлення через GitHub Actions тут не працює, дані оновлюються вручну в `assets/data.js`.

## Оновлення даних вручну

Усе в `assets/data.js`, файл прокоментований:
- `fanPage` — фан-сторінка: лічильники, біо, `history` (рядок `{ date: "2026-11-20", followers: 15800 }` при кожній перевірці) і `postsList`.
- Пости вручну: `{ url: "https://www.instagram.com/p/КОД/", date: "2026-11-08", likes: 812, comments: 24 }`. Такі пости показуються офіційним віджетом Instagram, а сортування й аналітика рахуються з ваших цифр.
- `athlete` — профіль @cmpulisic для окремого віджета, так само.
- Поки постів немає, у стрічці показується живе превʼю профілю з Instagram (`instagram.com/<профіль>/embed/`). Це неофіційний режим вбудовування: Instagram може його не показати, тоді лишається кнопка переходу на профіль.
- `fixtures`, `recentResults`, `standings`, `clubStats`: розклад, результати, таблиці, статистика.

## Автооновлення (необов'язково, безкоштовно)

Скрипт запускається щодня й записує `data/live.json`. Сторінка сама накладає ці дані поверх знімка.

1. **Футбол.** Зареєструйтеся на football-data.org (безкоштовний план) і додайте токен у репозиторій: Settings → Secrets and variables → Actions → *New repository secret*, назва `FOOTBALL_DATA_TOKEN`. Після цього таблиця Серії А, матчі й результати Мілана оновлюватимуться автоматично. Безкоштовний план не охоплює Лігу Європи та матчі збірної США, тож їх і далі додають у `data.js` вручну.
2. **Instagram (легальний шлях через офіційний API).** Потрібні власний акаунт Instagram типу Business або Creator, прив'язаний до сторінки Facebook, і застосунок на developers.facebook.com з дозволами `instagram_basic`, `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement` і `business_management` (без `instagram_manage_insights` Meta відповідає помилкою «(#10) Application does not have permission»). Додайте секрети `IG_USER_ID` (ID вашого бізнес-акаунта) та `IG_ACCESS_TOKEN` (довгостроковий токен). Метод Business Discovery повертає публічні дані інших бізнес- і creator-акаунтів: підписників, біо, а також останні пости з картинками, лайками й коментарями (50 постів фан-сторінки, 12 постів гравця). Тоді стрічка стає сіткою превʼю з лічильниками, а графіки наповнюються щодня самі. `@c.pulisic11` має категорію «Personal blog», тобто це професійний акаунт, і метод має з ним працювати. Профілі можна змінити змінними `FAN_HANDLE` і `ATHLETE_HANDLE` (Settings → Variables).
3. Перший запуск вручну: вкладка Actions → *Update data* → *Run workflow*.

Без секретів скрипт нічого не ламає, просто пропускає відповідний блок.

## Обмеження, про які варто знати

- Instagram не надає відкритого API без авторизації. Без кроку 2 цифри фан-сторінки взяті з її профілю станом на 9.11.2026 (15,7 тис. — округлено Instagram), а цифри @cmpulisic — з публічних трекерів (HypeAuditor, Instastatistics).
- Історії підписників фан-сторінки у відкритому доступі немає, тому графік починається з однієї точки й наповнюється далі.
- Час матчів у знімку збережено з часовим поясом, а сторінка показує його в часовому поясі відвідувача.
